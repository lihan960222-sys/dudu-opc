# 在 Windows 管理页设置角色目录

1. 打开管理首页，在员工档案中选择管家或员工，可修改名称、头像、职责和执行引擎。创建员工时，从模型列表选取当前账户可用的模型。老板也可以在飞书告诉管家缺什么人，回到后台打开待审的建员卡补全资料并确认。
2. 在工作目录栏粘贴已有文件夹的绝对路径，或从旁边的目录浏览器选取。远程打开后台时，这里选择的也是家里主机上的目录。每个角色各用一个目录，目录之间不能互相嵌套。
3. 点击 **Open role folder** 打开资源管理器。可自行创建「资料」「产物」子目录，单项任务的材料放在「任务/任务标识」内。已有文件会保留。
4. 用 UTF-8 编辑目录根部的 **AGENTS.md**。保留文件顶部两行分隔符和中间的 `default_model` 设置，替换成 Codex 模型列表中显示的完整模型 ID。正文可写职责、验收条件和汇报要求。下一轮开始时，后台重新读取并校验配置。已有同名文件也要符合这个格式。

文件格式示例，模型占位符须替换：

```markdown
---
default_model: MODEL_ID
---

按图纸逐项核对焊接尺寸。回报时写清图纸版本、实测值、单位和未确认的尺寸。
```

本地改名后，历史会话仍关联原角色 ID。飞书里显示的机器人名称由对应的飞书应用管理，改名时请一并核对。正在处理的会话保留创建时的工作目录；要在新目录执行，请新建会话。
