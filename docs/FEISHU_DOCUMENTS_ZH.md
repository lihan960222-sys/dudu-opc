# 用嘟嘟把私聊里的文字写成飞书文档

在和嘟嘟的单聊里发下面这条消息。嘟嘟会在你选定的文件夹里新建《周报》，写入正文，再把链接回给你。

```text
写飞书文档 周报
# 本周进展
已完成首轮验收。
## 下周安排
周三复核客户反馈。
```

要把嘟嘟先前的回答整理成文档，用飞书的「回复」直接选中那条已完成的回答，然后发「写飞书文档 客户反馈整理」。你在指令第二行另写了正文时，文档采用你写的正文。

要保存一次私聊分析，请直接回复嘟嘟发给你的 Codex 摘要，再发「写飞书文档 项目摘要」。嘟嘟会核对联系人、负责员工和个人授权，只把单独保存的分析要点写进文档。回复里列出的聊天原文不会随摘要写入。对于旧版摘要、本机摘录或没有可写入要点的回答，可以手动挑选文字，粘贴到指令第二行。

## 首次设置

1. 在飞书开放平台给嘟嘟的应用开通用户身份权限 `docx:document:create` 和 `docx:document:write_only`，发布应用的新版本。第一个权限允许建档，第二个权限允许写入正文。还需开通 `offline_access`，方便嘟嘟在授权有效期内继续使用。[创建文档](https://open.feishu.cn/document/server-docs/docs/docs/docx-v1/document/create.md) · [创建文档块](https://open.feishu.cn/document/ukTMukTMukTM/uUDN04SN0QjL1QDN/document-docx/docx-v1/document-block-children/create.md)
2. 在本机管理页打开「家庭主机 → 飞书个人授权」，展开「在飞书开放平台开通权限」，把页面显示的回调地址填入应用的「安全设置 → 重定向 URL」。发布配置后，点「授权新建文档」，用你自己的飞书账号登录。用同一账号打开目标文件夹，确认能在里面新建文档，也确认已有协作者适合看这些内容。链接按文件夹和飞书现有权限打开，嘟嘟不会替你更改分享设置。
3. 在管理页打开「家庭主机 → 飞书个人授权」，把完整的云盘文件夹链接粘贴到「新建飞书文档」，点击「保存文件夹」。清空后保存即可停用。手动预配时，例如链接 `https://example.feishu.cn/drive/folder/AbC123` 对应以下字段。

```json
{
  "document_target": {
    "folder_token": "AbC123",
    "tenant_origin": "https://example.feishu.cn"
  }
}
```

每条指令只建一份新文档。标题最多 200 个字符，正文最多 24000 个字符。每个非空行形成一段，超过 1200 字的行会拆段，整篇最多 50 段。`#`、`##`、`###` 后面加空格，会排成三级标题。其他文字按原文写入。当前支持私聊中的文字和你直接回复的嘟嘟答案；附件、群聊内容及已有文档不在这条指令的范围内。

## 没收到完整文档时

如果嘟嘟提示「待核对」，先看回复里的文档链接。有链接代表文档已经创建，可以直接补齐正文。没有链接时，请到目标文件夹按标题查找。确认没有同名文档后，再发一条新指令。同一条飞书消息重复送达或服务中途重启时，嘟嘟会保留第一次的处理记录。对于飞书尚未确认的创建或写入，它会等你核对，避免重复建档。

如果嘟嘟提示需要授权，请在本机重新连接飞书账号，并用这个账号在同一文件夹试着手动新建文档。
